## Not verifiable here

- Docker images were not built and the stack was not started (no Docker daemon).
- The dashboard was not opened in a browser: the proxy blocks the CDNs. The CSP allows the Tailwind Play CDN including `'unsafe-eval'` to avoid breaking it; check the browser console on first run. SRI hashes were computed from the npm tarballs, which jsDelivr and unpkg serve unchanged.
- The legacy inference server's API key path was tested with stubbed dependencies, not inside its container.
- CI was not run (no GitHub API access). Workflows parse; action SHAs come from `git ls-remote`.
- Latency figures in `reports/metrics.json` come from this shared audit container, not a GitHub runner.
